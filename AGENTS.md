# Stack Day

Stack Day is a lightweight habit-tracking app focused on helping users
build consistency through daily actions.

It is a habit tracker, not a todo or productivity app.

## Stack

- Swift 6
- SwiftUI
- Swift Concurrency
- Swift Testing

## Architecture

Use MVVM with UseCases and Repositories.

## Project Documents

Read the relevant document before changing product behavior:

- `docs/product.md`: product direction and MVP scope
- `docs/policies.md`: rules that implementation and tests must follow
- `docs/planning.md`: development goals and completion criteria

## Rules

- Keep changes scoped.
- Add behavior-focused tests for behavior changes.
- Build and test after changes.

## Completion

After completing a task:

- Summarize what was implemented or changed.
- Mention important implementation decisions or tradeoffs.
- Report build and test results.
- Note any remaining issues or follow-up work.
